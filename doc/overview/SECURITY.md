Security Policy
===============
Supported Versions
------------------
We provide security updates for the latest release of FastSurfer. Please update to it before reporting a problem.

| Version        | Supported |
|----------------|-----------|
| Latest release | ✅        |
| Older releases | ❌        |

The latest release and the list of all releases are on the
[releases page](https://github.com/Deep-MI/FastSurfer/releases).

Reporting a Vulnerability
-------------------------
Please report vulnerabilities as [GitHub issues](https://github.com/Deep-MI/FastSurfer/issues) and use
"Vulnerability" in the title; you can expect a quick response. If possible, include a description of the
vulnerability and how to resolve it, for example by updating dependencies. Thanks for your contribution!
